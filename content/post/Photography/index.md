# 摄影的艺术

> [!NOTE] 入门提示
> 面向新手的摄影基础科普：从曝光三要素、器材构成到图片与视频规格，帮你快速建立一套可用的概念框架。


## 一、曝光与常用参数

| 参数 | 说明与建议 |
| --- | --- |
| 光圈 | 控制进光量与景深。建议使用区间 F4–F11，画质与景深较均衡（特殊情况如大光圈虚化、微距除外）。 |
| 快门速度 | 控制曝光时间与运动表现。速度快可冻结动作，速度慢可拍摄轨迹或流水（慢门需配合三脚架）。 |
| ISO | 感光度。建议尽量使用原生 ISO，以获得更好的画质与更少的噪点。 |
| 白平衡 | 校正不同光源下的色调，使白色还原为白色，决定画面冷暖倾向。 |
| 曝光补偿（EV 值） | 在自动测光基础上微调亮度。光线复杂时较实用，建议配合自动曝光使用。 |

> 小结：光圈、快门、ISO 三者共同决定曝光量（曝光三要素），白平衡与曝光补偿则用于控制色彩与亮度倾向。

## 二、认识传感器、镜头与滤镜

### 1. 传感器

- **像素量**：决定图像的分辨率与可裁切空间。
- **动态范围**：决定画面同时保留高光与暗部细节的能力。

### 2. 镜头

- **焦段**：镜头的焦距范围，决定视角的宽窄。
- **等效焦距**：换算到 35mm 全画幅后的等效视角，便于跨画幅比较。
- **定焦 / 变焦**：定焦画质与光圈通常更优，变焦取景更灵活。
- **对焦**：分为自动对焦（AF）与手动对焦（MF）。

### 3. 滤镜

- **UV 镜**：过滤紫外线并保护镜头。
- **ND 镜**：减光镜，用于强光下降低快门速度或增大光圈。
- **增广镜**：附加镜，扩展镜头的广角视野。

## 三、图片与视频规格

### 1. 文件格式

| 类型 | 常见格式 |
| --- | --- |
| 照片 | JPEG、PNG、RAW |
| 视频 | MP4、MOV |

### 2. 关键规格

| 规格 | 说明 |
| --- | --- |
| 分辨率 | 画面的像素尺寸，如 1920×1080、3840×2160。 |
| 帧率 | FPS（Frames Per Second），每秒传输/播放的帧数，影响画面流畅度。 |
| 码率（比特率） | Mbps（Megabits per second），每秒传输的比特数量，影响画质与文件体积。 |

## 四、色彩模式

> 提示：建议进阶使用 HLG 和 D-LOG，以获得更大的后期调色空间。

| 色彩模式 | 特点 |
| --- | --- |
| 普通（Standard） | 直出色彩，方便即时使用。 |
| HLG（HDR） | 即 HDR（High Dynamic Range Imaging，高动态范围），兼顾高光与暗部。 |
| D-LOG | 画面偏灰，保留最多细节，适合专业后期。 |
| D-Cinelike | 介于普通与 D-LOG 之间，兼顾宽容度与观感。 |

---

## 五、进阶拓展

- **色深**：8bit 与 10bit，决定色彩层次与后期空间。
- **色度采样**：如 4:2:0、4:2:2，影响色彩信息的保留程度。
