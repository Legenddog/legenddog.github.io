## 摄影入门常用术语科普

|  色彩模式                |                                                  |
|  ------------------     |    -------------------------------------------   |
|  光圈                   |   建议使用区间F4-11（不包含玄学情况                 |
|  快门速度                |                                                  |
|  ISO                    |   建议使用原生ISO                                 |
|  白平衡                  |   介于普通和D-LOG之间                             |
|  曝光（EV值）            |   建议可以使用自动曝光                             |
