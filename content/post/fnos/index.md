## 一、什么是 NAS？

**NAS（Network Attached Storage，网络附加存储）** 可以简单理解为"接在局域网里、专门用来存数据的电脑"。它通过网络提供文件共享、备份、影音播放、下载等能力，让你在手机、电脑、电视上随时访问同一份数据。

一台典型 NAS 由两部分组成：

| 组成 | 说明 |
| --- | --- |
| **硬件** | 主机（成品机 / 旧电脑 / 迷你主机 / 自攒）、硬盘、网线 |
| **系统（NAS OS）** | 决定功能、界面和易用性的核心软件，如群晖 DSM、飞牛 fnOS、TrueNAS 等 |

硬件决定性能上限，**系统决定使用体验**。因此选对 NAS 系统，往往比堆硬件更重要。

## 二、主流 NAS 系统概览

NAS 系统大致可分为三类：**闭源成品型**、**开源DIY型**。

### 1. 闭源成品型（适合不想折腾的用户）

| 系统 | 特点 | 优点 | 缺点 |
| --- | --- | --- | --- |
| **群晖 DSM** | NAS 行业标杆 | 生态最成熟、套件中心应用丰富、备份/影音/监控完善、多端 App 体验好 | 硬件绑定、价格偏高、配置偏保守 |
| **威联通 QTS** | 企业功能丰富 | 网络能力强、虚拟化与备份功能多 | 界面偏复杂、曾存在安全争议 |
| **绿联 UGOS Pro / 极空间 ZOS** | 国产成品机系统 | 开箱即用、小白友好、本地化适配好 | 生态较新、硬件绑定 |

> 特点：**省心、稳定**，但价格和硬件选择受限。

### 2. 开源 DIY 型（适合爱折腾的用户）

| 系统 | 特点 | 优点 | 缺点 |
| --- | --- | --- | --- |
| **TrueNAS（Core / Scale）** | 基于 ZFS 的企业级开源系统 | 数据完整性校验、快照、自愈，可靠性极高 | 内存要求高（建议 16GB+）、学习曲线陡 |
| **Unraid** | 灵活扩容 + 容器/虚拟机全能 | 可混用不同容量硬盘、仅需 1 块校验盘、Docker/KVM 强 | 需付费授权、逻辑上手需时间 |
| **OpenMediaVault（OMV）** | 基于 Debian 的轻量系统 | 开源免费、资源占用低、硬件要求低 | 功能依赖插件、界面较简陋 |
| **XigmaNAS** | 轻量基础存储 | 低配置设备友好、ZFS 支持 | 界面老旧、功能单一 |
| **ZimaOS** | 简洁 + 远程访问 | 界面清爽、整合 ZeroTier 无需公网 IP | 生态较新 |

> 特点：**免费、自由、可玩性高**，但需要一定的动手能力和 Linux 基础。

### 3. 国产新势力：飞牛 fnOS

**飞牛 fnOS（FnNAS）** 是近两年热度极高的国产免费 NAS 系统，基于 Debian 打造，对中文用户极其友好，界面设计现代化。

**核心优势：**

- ✅ **免费**，支持在自有硬件上安装，可复用旧电脑、迷你主机等闲置设备
- ✅ **硬件自由**，主流 x86 架构硬件均可安装，兼容性强
- ✅ **界面清爽**，设计风格接近 macOS / 群晖，中文适配到位
- ✅ **功能齐全**，内置 Docker、相册、下载、影视墙、备份、远程访问等
- ✅ **支持多种 RAID 模式**（RAID 0/1/5/6/10 及 JBOD 等），兼顾数据安全
- ✅ 提供 **FN Connect** 远程访问、DDNS、P2P 等多种远程方案

**需要注意：**

- ⚠️ 系统仍在快速迭代，跨大版本升级前建议先做好备份
- ⚠️ 目前主要面向 x86 架构（ARM 版处于公测阶段）
- ⚠️ 相对老牌系统，生态与社区仍在成长中

**适合人群：** 喜欢尝鲜、追求免费、希望用旧设备搭建私有云的家庭用户与轻量玩家。

## 三、飞牛 fnOS 物理机安装实战（重点）

下面以 **x86 物理机**为例，完整讲解从下载到初始化的全过程。核心参考飞牛官方帮助中心文档。

2.4号京东下单了中柏n150的双网口小主机用于nas系统尝鲜


### 3.1 安装前准备

**硬件要求：**

- 一台 **x86 架构**主机（旧笔记本、迷你主机、自攒机均可）
- 至少 **一块硬盘**用作系统盘，**强烈推荐 SSD**（系统运行更快）
- 一根**有线网线**（暂时不支持仅有无线网卡安装）
- 电源、显示器、键盘（鼠标非必需）
- 一个 **U 盘**（建议容量不小于 8GB，用于制作引导盘）

> 💡 **提示**：fnOS 的系统只会安装到**一块硬盘**上。系统盘除系统分区外的剩余空间，仍可用于创建存储空间来存文件。因此系统盘容量按需选择即可。

### 3.2 第一步：下载安装镜像

前往**飞牛官网（fnnas.com）** 的下载页面，下载最新的系统安装 **ISO 镜像**（ARM 设备则下载对应镜像）。

> 💡 下载后建议**核对官方公布的 MD5 值**，避免使用损坏的镜像导致安装失败。

### 3.3 第二步：制作引导 U 盘

在另一台电脑上，使用写盘工具将镜像烧录到 U 盘。常用工具：

- **Rufus**（Windows 推荐）
- **BalenaEtcher**（跨平台）
- **Ventoy**（可多镜像共存）
- **dd**（Linux / macOS）

以 **Rufus** 为例：

1. 插入 U 盘，打开 Rufus
2. **设备**：选择要写入的 U 盘
3. **引导类型选择**：点击"选择"，找到并打开下载好的 fnOS 镜像文件（`.iso` 或 `.img`）
4. 其他参数保持默认，点击 **"开始"**
5. 进度条显示 **"准备就绪"** 即写入完成，可拔出 U 盘

### 3.4 第三步：BIOS/UEFI 设置

将制作好的引导盘插入目标主机，开机时**快速反复按**进入 Boot 菜单的热键。不同主板热键不同，常见的有：

`F2`、`F7`、`F8`、`F10`、`F11`、`F12`、`Esc`、`Delete`

在 BIOS/UEFI 中主要进行两项调整：

1. **关闭安全启动（Secure Boot）**：在 Security 或 Boot 菜单中将其设为 **Disabled**（大多数 Linux 系统正常启动的前提）
2. **调整启动顺序**：将 U 盘设为**第一启动项**（支持 UEFI 的优先用 UEFI 模式）

保存设置并退出，设备将从 U 盘启动。

### 3.5 第四步：运行安装程序

从 U 盘引导后，进入 fnOS 安装页面。**推荐选择 `Graphical Install`（图形化安装流程）**，回车进入下一步。

> ⚠️ 若提示 **"暂不支持在当前模式下安装，请前往 BIOS 关闭 Secure Boot 后重试"**，请回到 BIOS 关闭 Secure Boot。
>
> ⚠️ 若图形化安装过程中报错失败，可重启设备，在这一步改选 **`Rescuing Install`（应急模式安装）** 重试。

### 3.6 第五步：选择系统盘并设置分区

1. **选择系统盘**：用方向键切换选择用于安装系统的硬盘，回车（或 `Alt+N`）进入下一步
2. **设置系统分区和 Swap 大小**：
   - 系统盘容量充足时，建议**系统分区设置为 64 GB**
   - Swap 分区大小已按物理内存自动计算推荐值，可按硬件情况自行调整
   - 若安装在虚拟机中，可适当减小

确认后回车（或 `Alt+N`）进入下一步。

### 3.7 第六步：确认格式化并安装

所选择的系统盘**将被格式化，所有内容会被删除**，请务必确认选择无误。

回车（或 `Alt+O`）确认后，开始自动安装，等待进度完成。

### 3.8 第七步：设置网络

安装完成后会自动进入网络设置界面：

- 系统会自动检测已连接的网卡并**通过 DHCP 获取动态 IP**
- 若网卡未开启 DHCP，需**手动设置 IP、子网掩码、网关、DNS**

确认后回车（或 `Alt+S`）保存设置。

### 3.9 第八步：重启设备

网络设置保存成功后：

1. 将引导盘（U 盘）从主机上**拔出**
2. 回车（或 `Alt+O`）**重启系统**

设备重启后会**自动进入终端登录页**，这意味着系统已成功安装并启动！

> 📌 请**记住屏幕上显示的 IP 地址**，接下来你将通过浏览器访问它。

### 3.10 第九步：Web 初始化配置

使用同一局域网内的另一台电脑或手机，在浏览器中输入刚才的 IP 地址（例如 `http://192.168.1.100`），进入 fnOS 登录界面。

首次访问会进入**初始化向导**：

1. **设置设备名称与管理账号**：为 NAS 起名，并创建管理员账号和密码（该账号拥有最高权限，请妥善保管）
2. **创建存储池**：进入"存储管理"，将硬盘组合起来。支持多种 RAID 模式：
   - 单块硬盘 → 直接创建**基础存储池**即可
   - 多块硬盘 → 按数据安全与性能需求选择 **RAID 0 / 1 / 5 / 6 / 10 / JBOD** 等
3. **创建卷**：在存储池之上创建用来实际存放数据的"卷"，设定大小和名称

至此，你的飞牛 NAS 就已**准备就绪**！

> 💡 **小贴士**：fnOS 默认 Web 端口为 **5667**（HTTPS 访问），如在路由器或防火墙修改过端口，请使用对应端口访问。

## 四、安装后的常用配置建议

### 4.1 设置静态 IP（推荐）

为方便长期稳定访问，建议在路由器中为 NAS 绑定固定 IP，或在系统网络设置中手动指定静态 IP。

### 4.2 开启所需服务

- **文件共享**：SMB / NFS / WebDAV，方便各平台访问
- **远程访问**：可选用 FN Connect、DDNS、P2P 等方式，公网 IP 用户可直连
- **Docker**：扩展更多应用（下载、影音、网盘同步等）
- **备份**：配置快照、定时备份，落实"数据安全优先"原则

### 4.3 账号与权限

fnOS 分为**管理员**和**普通用户**两种角色，可为家庭成员分别开通账号并设置精细化的文件权限。

## 五、常见问题与排障

| 问题 | 解决办法 |
| --- | --- |
| 提示需关闭 Secure Boot | 进入 BIOS，将 Secure Boot 设为 Disabled |
| 图形化安装报错 | 重启后改选 `Rescuing Install`（应急模式）重试 |
| 找不到 U 盘启动项 | 检查 U 盘是否为第一启动项，或更换 USB 接口 |
| 无法通过浏览器访问 | 确认电脑与 NAS 在同一局域网，核对 IP 与端口 |
| 系统盘数据丢失 | 安装会格式化系统盘，重装前请用快照/备份应用先行备份 |

> ⚠️ **再次强调**：安装过程中系统盘会被格式化，请务必确认选择的是**正确的硬盘**，并提前备份重要数据。

## 六、总结与建议

- **想省心、预算充足** → 群晖 DSM 等成品机
- **追求数据安全、有技术基础** → TrueNAS
- **喜欢灵活扩容与容器/虚拟化** → Unraid
- **免费尝鲜、复用旧设备、看重中文体验** → **飞牛 fnOS** ⭐

飞牛 fnOS 凭借**免费、硬件自由、界面友好、功能全面**的特点，成为当下入门 NAS 的极佳选择。它把过去需要命令行折腾的事情，变成了图形化、开箱即用的体验，非常适合家庭用户用一台旧电脑或迷你主机，低成本搭建属于自己的私有云。

> 数据无价，无论使用哪套系统，请**务必做好备份**——本地备份 + 异地备份，才是数据安全最可靠的保障。
