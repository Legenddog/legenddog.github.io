# iStoreOS 物理机安装（从硬路由到软路由以及OpenWrt 生态漫谈）

>[!IMPORTANT]一句话导读：
> 硬路由图的是省心稳定，软路由玩的是无限可能。本文先聊聊两种路由的历史与分野，再把重点放在 **iStoreOS 的物理机安装** 上，最后顺带聊聊它背后的 OpenWrt 家族。

---

## 一、先搞清楚：软路由到底是什么

我们平常买的、带好几根天线的那个盒子，叫 **硬路由（硬件路由器）**。它内部有专门的路由转发芯片、固化的固件系统，出厂就设定好干一件事：把数据包从一个网口转发到另一个网口。即插即用、稳定省电，老人小孩都能用。

**软路由（Software Router）** 则完全不同。它的本质是 **一台通用计算机**——x86 架构的处理器、内存、固态硬盘，只不过装了一套专门的路由操作系统（如 OpenWrt、iStoreOS、爱快等），靠软件来实现路由功能。

一句话概括：

> 硬路由是"专用设备 + 封闭固件"，软路由是"通用硬件 + 可自由安装的系统软件"。

需要特别说明的是：**"软路由"描述的是一种解决方案，而"OpenWrt""iStoreOS""爱快"指的是跑在软路由硬件上的具体操作系统/固件。** 这两个概念经常被混用，先分清楚，后面的理解会顺很多。


>
>衍生阅读：OpenWrt 生态是怎样的一棵树
>
>iStoreOS 并非凭空诞生，它 **基于 OpenWrt 构建**。理解 OpenWrt，就理解了软路由系统的大半个世界。
>
>- **OpenWrt** 本身是一个面向嵌入式设备的开源 Linux 发行版，最初是 Linksys WRT54G 路由器固件的一个开源替代项目，后来发展成事实上的行业标准。它的 **LuCI 界面偏极客向**，插件需要自行编译或添加源，上手门槛较高。
>- **ImmortalWrt** 是 OpenWrt 的 **国内优化分支**，针对国内网络环境做了适配，内置大量本地化插件。
>- **iStoreOS** 则是在 OpenWrt 基础上 **重新包装的家用友好发行版**：把复杂的依赖关系封装进图形化软件商店 iStore，界面接近商业路由器，**极大降低了新手门槛**。
>
>因此可以这样理解这棵"家族树"：
>
>```text
>OpenWrt（底层开源框架）
>├── ImmortalWrt（国内优化分支）
>└── iStoreOS（家用友好发行版，内置 iStore 商店）
>```
>
>**同源带来的好处：**
>
>- 生态互通：OpenWrt 的插件、教程、社区资源基本都能在 iStoreOS 上参考使用。
>- 经验可迁移：学会 iStoreOS 后，切换到原版 OpenWrt 或 ImmortalWrt，思路是一致的。
>

## 二、软路由与硬路由的简史与分野

### 2.1 硬路由：从企业机房里走出来

早期的路由功能由专门的路由器设备承担。这类设备采用 **ASIC 专用芯片** 做硬件级转发，不占用 CPU 资源，因此小包转发性能极强、延迟低、功耗也低。随着家用宽带普及，厂商把这套思路做成了消费级产品——就是今天我们熟悉的家用无线路由器。

它的优点是显而易见的：稳定、省电、开箱即用、故障率低。但代价是 **功能锁死**——厂商给什么就用什么，想加个广告过滤、内网穿透，只能等官方固件更新（往往等不到）。

### 2.2 软路由：用"电脑"来干路由器的活

软路由的思路其实更早，起源于 **用一台 PC/服务器 + Linux 软件** 来实现路由功能。早期的典型代表是运行 Linux、搭配 iptables 做 NAT 和转发的方案，多用于企业、网吧、IDC 等场景——图的就是 **便宜、灵活、算力强**。

后来随着开源路由系统（尤其是 OpenWrt 及其分支）成熟，加上低功耗小主机、迷你主机、工控机价格下探，软路由才真正走进家庭用户和网络爱好者的视野。

### 2.3 核心差异对比

| 维度 | 硬路由 | 软路由 |
| --- | --- | --- |
| 本质 | 厂商预装固定系统的专用设备 | 通用硬件 + 自行安装的路由系统 |
| 转发方式 | ASIC 硬件转发，小包性能强 | CPU 逐包处理，依赖单核性能与 offload |
| 功能扩展 | 受限，基本由厂商决定 | 极强，可装插件/Docker/各类服务 |
| 配置难度 | 即插即用，零门槛 | 需要一定动手与网络基础 |
| 功耗/稳定性 | 低功耗、长期稳定 | 需注意散热，稳定性取决于硬件与固件 |
| 无线能力 | 自带 Wi-Fi，信号调校成熟 | **通常不带 Wi-Fi**，需外接 AP |
| 典型形态 | 家用无线路由器 | x86 小主机 / 旧电脑 / 虚拟机 / 单板计算机 |

### 2.4 两者不是替代关系，而是"黄金组合"

很多高手家里的最终方案并不是"二选一"，而是分工协作：

- **软路由管"大脑"（算力）**：一台多网口 x86 小主机刷入 iStoreOS 或 OpenWrt，接在光猫后面做主路由，负责拨号、流量分流、DNS 防污染、广告拦截等"费脑力"的活。
- **硬路由管"四肢"（信号）**：把高性能无线路由器切换为 **AP 模式**（关闭其路由功能），只负责发射全屋 Wi-Fi 信号。

## 三、为什么越来越多人选择软路由

1. **统一网络管理**：一次设置，家里所有手机、电视、游戏机自动生效，无需逐台配置。
2. **强大的插件生态**：广告过滤、内网穿透、多线负载均衡、QoS 流控、DNS 优化等。
3. **一台"家庭网络中枢"**：可以在上面跑 Docker、Home Assistant、Alist 等轻量服务。
4. **性能上限高**：可换网卡、加内存、上多核 CPU，甚至上万兆网卡。

> 但也要有心理准备：软路由终究不是完全开箱即用，需要一定的"折腾"精神。

## 四、主流软路由系统一览

| 系统 | 定位 | 上手难度 | 特点 |
| --- | --- | --- | --- |
| **OpenWrt（原版）** | 底层开源路由框架 | 较高 | 高度可定制，社区庞大，几乎行业标准 |
| **ImmortalWrt** | OpenWrt 的国内优化分支 | 中等 | 内置大量本地化适配插件 |
| **iStoreOS** | 基于 OpenWrt 的家用友好发行版 | 较低 | 图形化软件商店 iStore，界面接近商业路由器 |
| **爱快 iKuai** | 独立商业软路由系统 | 低 | 流控/多拨强，界面简洁 |
| **RouterOS** | Mikrotik 商业路由系统 | 较高 | 工业级稳定，功能极强 |

其中 **iStoreOS 因为"好看、好装、插件依赖自动处理"，成为很多新手的入门首选**，也是本文的主角。

## 五、主角登场：iStoreOS 物理机安装全流程

> **本节为全文重点。** 所谓"物理机安装"，就是把 iStoreOS 直接安装到一台真实的小主机/工控机/旧电脑的硬盘上，而不是跑在虚拟机里。

### 5.1 准备工作

**硬件清单：**

- 一台 x86 架构的 **多网口小主机 / 工控机 / 旧电脑**（建议至少 2 个网口：1 个 WAN + 1 个 LAN）
- 一个 **U 盘**（8GB 以上，会被格式化，请先清空数据）
- 一台 **Windows 电脑**（用于制作启动盘）
- **显示器 + 键盘**（用于首次安装时接在小主机上操作）
- 网线若干

**下载固件：**

访问 KoolCenter 固件下载服务器：

- **传统 BIOS / Legacy 启动**：`https://fw.koolcenter.com/iStoreOS/x86_64/`
- **UEFI 启动**（现代硬件通常选这个）：`https://fw.koolcenter.com/iStoreOS/x86_64_efi/`

选择目录中 **最新版本** 的固件文件下载即可，**下载完成后不需要解压**。

> ⚠️ 特别注意：**Legacy 固件和 EFI 固件不能混用**。你的小主机主板支持 UEFI，就下载 `x86_64_efi/` 里的；只支持传统 BIOS，就下载 `x86_64/` 里的。选错会导致无法启动。

### 5.2 制作启动盘

在 Windows 电脑上使用 **Rufus**（下载地址：https://rufus.ie/zh/ ）：

1. 插入 U 盘，打开 Rufus。
2. 在"设备"处选择你的 U 盘。
3. 在"引导类型选择"处，点击右侧按钮，选中刚下载的 iStoreOS 固件。
4. 分区方案按固件类型选择（EFI 固件对应 GPT / UEFI；Legacy 固件对应 MBR / BIOS）。
5. 点击 **开始**，等待写入完成。

> 也可以用 balenaEtcher 等工具，操作类似。制作过程会 **格式化 U 盘**，请务必提前备份。

### 5.3 BIOS 设置与 U 盘启动

1. 将 **U 盘、显示器、键盘** 接好到小主机上。
2. 开机时 **连续点按快捷启动键**（常见为 F11、F12、F8、F10、ESC，具体取决于主板品牌，可自行查询）。
3. 在弹出的启动菜单中用方向键选择 **你的 U 盘**，回车进入。
4. 如果找不到 U 盘选项，可能是 U 盘兼容性问题，**换一个 U 盘** 通常能解决。
5. 若使用了 UEFI 固件，可能需要在 BIOS 中 **关闭 Secure Boot**，并确认引导模式为 UEFI。

### 5.4 把固件安装到硬盘（核心步骤）

成功从 U 盘启动后，你会看到一个 **命令行界面**。

1. 登录成功后，输入命令：

   ```bash
   quickstart
   ```

2. 在弹出的菜单中选择 **`Install X86`**（或类似"安装到 X86"的选项）。
3. 一路按 **确定 / 回车**，系统会询问要安装到哪块硬盘——**选中你的目标硬盘**（通常是内置 SSD）。
4. 确认后开始写入系统，等待进度完成。
5. 安装完成后 **拔掉 U 盘并重启**，系统就会从硬盘启动 iStoreOS 了。

> 💡 `quickstart` 是 iStoreOS/OpenWrt 的快捷命令菜单，安装、查看网口、修改 IP 等都能在这里完成。

### 5.5 确认 LAN 口并进入 Web 管理

1. 在 `quickstart` 菜单里选择 **`Show Interfaces`**，可以查看网线插到了哪个网口，以及当前 LAN 口的 IP 地址。
2. iStoreOS 默认 LAN 口 IP 一般为 **`192.168.100.1`**（不同版本可能略有差异，以实际显示为准）。
3. 用一根网线把电脑连接到 **LAN 口**，在浏览器输入该 IP，即可进入 Web 管理界面。
4. 默认账号：**`root`**，默认密码：**`password`**（首次登录后请立即修改）。

## 六、安装后的基础配置

进入 Web 界面后，建议按以下顺序做基础设置：

1. **设置 WAN 口**：将光猫网线接入 WAN 口，在"网络 → 接口"中配置拨号（PPPoE）或 DHCP。
2. **修改 LAN 网段**：如果你家已有主路由，建议把 iStoreOS 的 LAN 网段改到不同网段，避免冲突。
3. **修改默认密码**：安全第一，务必第一时间改掉 `password`。
4. **更新软件源 / 固件**：进入 iStore 应用商店检查更新。
5. **安装常用插件**：iStore 图形化商店里可安装广告过滤、内网穿透、Docker 等插件，依赖会自动处理，非常适合新手。
6. **旁路由玩法**：也可以把 iStoreOS 作为"旁路由"接在主路由的 LAN 上，只处理需要特殊策略的流量，再交回主路由上网。

## 七、常见问题与排错

| 现象 | 可能原因 | 解决思路 |
| --- | --- | --- |
| 找不到 U 盘启动项 | U 盘不兼容 / 快捷启动键不对 | 换 U 盘；查主板手册确认启动键 |
| 刷完无法启动 | Legacy 与 EFI 固件选错 | 重新下载对应类型固件再刷 |
| 进不去管理页面 | 网线插错网口 / 网段不在同一子网 | 用 `Show Interfaces` 确认 LAN 口与 IP；把电脑设成同网段 |
| 无线信号弱 | 软路由本身不带 Wi-Fi | 外接 AP，或把硬路由切 AP 模式 |
| 大带宽跑不满 | CPU 单核性能不足 / 未开 offload | 选更高性能 CPU；开启软件/硬件加速 |

---

## 八、结语

软路由不是硬路由的"平替"，而是另一种思路的延伸：把控制权交回自己手里，用通用硬件去承载更多可能。

如果你只是想安安静静上网，一台性能不错的硬路由原厂固件完全够用；但如果你想要广告过滤、内网穿透、多线分流，甚至把路由当成家庭网络的"小服务器"来折腾，那么在多网口小主机上装一套 **iStoreOS**，会是一个非常友好的起点——它既保留了 **OpenWrt 的开放基因**，又用图形化商店把门槛降了下来。

> **一句话总结：硬路由图的是省心稳定，软路由玩的是无限可能。适合自己的，才是最好的方案。**
